# Sample Prompts
Use these prompts in an MCP-compatible client.

## Basic discovery
What datasets are available?

## Dataset profile
Give me a profile of iris.csv.

## Columns
What are the numeric and categorical columns in iris.csv?

## Preview
Show me the first 5 rows of iris.csv.

## Summary statistics
Describe iris.csv using summary statistics.

## Correlation
Compute the correlation between `petal length (cm)` and `petal width (cm)` in iris.csv.

## Filtering
Show me 5 rows where `target_name` is `setosa`.

## Value counts
How many examples are there for each value in `target_name`?

## Full exploration
Use the explore dataset prompt for iris.csv and explain the key insights.
